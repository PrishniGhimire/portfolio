# Portfolio

Personal UI/UX portfolio of Prishni Ghimire — https://prishnighimire.com.np/

A single-file static site (`index.html`): no build step, no dependencies.

## Editing content
Open `index.html` and scroll to the `<script>` at the bottom. The `projects`
and `jobs` lists hold all project and experience content — edit or add items there.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
